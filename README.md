# Taller 6 — Diario de Restaurantes
1. En Eclipse, selecciona File → Import → General → Existing Projects into Workspace.
2. En Select root directory, selecciona la carpeta Taller Swing Restaurantes Esqueleto.
3. Selecciona el proyecto y pulsa Finish.
4. En src, abre el paquete uniandes.dpoo.swing.interfaz.principal.
5. Haz clic derecho en VentanaPrincipal.java y selecciona Run As → Java Application.
